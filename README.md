# Healthcare Nutrition Data Engineering Pipeline

An end-to-end data engineering project that demonstrates how healthcare and nutrition data can be collected, cleaned, transformed, validated, and loaded into a database for analysis.

## Project Overview

This project simulates a healthcare nutrition data pipeline using synthetic patient data.

The pipeline follows:

Raw Data → Data Extraction → Data Cleaning → Transformation → Data Quality Validation → SQL Database → Analytics

## Objectives

- Build an end-to-end ETL pipeline using Python
- Clean and validate healthcare nutrition data
- Store structured data in a SQL database
- Apply data quality checks
- Perform analytical queries
- Demonstrate practical Data Engineering skills in a healthcare context

## Technologies

- Python
- Pandas
- SQL
- MySQL
- ETL
- Data Quality Validation

## Dataset

The project uses synthetic healthcare and nutrition data.

No real patient or personally identifiable information is used.
